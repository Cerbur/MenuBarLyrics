# MenuBarLyrics

MenuBarLyrics 是一个轻量的 macOS 菜单栏歌词工具。它会读取 Music.app 当前播放的歌曲信息和本地歌词元数据，并在桌面下方显示一行悬浮歌词。

## 功能

- 常驻 macOS 菜单栏，可从菜单显示、隐藏歌词或退出应用。
- 每秒轮询一次 Music.app 当前播放状态。
- 通过 AppleScript 读取歌曲名、艺人、播放进度、时长和 `lyrics` 元数据。
- 支持解析 LRC 风格时间戳，例如 `[00:12.50]`。
- 当歌词没有时间戳时，根据播放进度估算当前歌词行。
- 使用点击穿透的悬浮窗口显示歌词，不抢占当前应用焦点。

## 系统要求

- macOS 14 或更新版本
- Swift 6.0 或更新版本
- Music.app
- 当前歌曲需要在本地音乐资料库元数据中包含可读取的歌词

## 运行

```bash
swift run
```

首次启动时，macOS 可能会请求“自动化”权限，用于允许 MenuBarLyrics 控制 Music.app 和 System Events。没有该权限时，应用无法读取当前播放信息。

## 使用限制

Apple Music 的实时同步歌词目前没有公开的 macOS API 可供第三方应用读取。本项目读取的是 Music.app 本地资料库中的 `lyrics` 元数据。

如果歌曲没有可读取的歌词元数据，悬浮窗口会显示歌曲名、艺人和未找到歌词的提示。
